## 技术实现

### 错误位置信息格式

```zig
pub const Location = struct {
    line: usize,
    column: usize,
};

pub const ParserError = error{
    UnexpectedToken,
    InvalidSyntax,
    OutOfMemory,
    UnexpectedTokenAtLocation(Location),
};
```

### 调试工具

```zig
// main.zig 中新增参数
if (std.mem.eql(u8, input, "--debug")) {
    try runDebugMode(allocator, &repl);
}
} else if (std.mem.eql(u8, input, "--ast")) {
    try printAST(allocator, input);
} else if (std.mem.eql(u8, input, "--tokens")) {
    try printTokens(allocator, input);
}
```
