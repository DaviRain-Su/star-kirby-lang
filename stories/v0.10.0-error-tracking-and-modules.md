## 测试用例

```monkey
// 命令行参数
// script.monkey:
puts(args());
// 运行: zig build run -- script.monkey arg1 arg2
// 输出: ["script.monkey", "arg1", "arg2"]

// 模块导入
// utils.monkey:
let double = fn(x) { x * 2 };
let triple = fn(x) { x * 3 };

// main.monkey:
import("utils.monkey");
puts(double(5));  // 10
puts(triple(5));  // 15
```
