## 测试用例

```monkey
// 随机数
rand();              // 随机整数
rand(10);            // 0-9
rand(1, 100);        // 1-99
shuffle([1, 2, 3]);  // 随机顺序

// 类型检查
isInt(42);           // true
isStr("hello");      // true
isArray([1, 2]);     // true
isFunc(fn(x) { x }); // true

// 字符串函数
startsWith("hello", "hel");  // true
endsWith("hello", "lo");     // true
repeat("ab", 3);             // "ababab"
padLeft("42", 5, "0");       // "00042"

// 数学函数
sign(-5);            // -1
sign(0);             // 0
sign(5);             // 1
clamp(15, 0, 10);    // 10
gcd(12, 8);          // 4
lcm(4, 6);           // 12
avg([1, 2, 3, 4, 5]); // 3
product([1, 2, 3, 4]); // 24

// 实用函数
assert(true, "ok");          // null (通过)
typeof(42);                  // "INTEGER"
default(null, "fallback");   // "fallback"
default("value", "fallback"); // "value"
```
