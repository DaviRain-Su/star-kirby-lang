## 技术设计

### 索引赋值语法

```monkey
// 数组索引赋值
let arr = [1, 2, 3];
arr[0] = 10;        // arr 变为 [10, 2, 3]

// 哈希键赋值
let h = {"a": 1};
h["b"] = 2;         // h 变为 {"a": 1, "b": 2}

// 嵌套索引赋值
let matrix = [[1, 2], [3, 4]];
matrix[0][1] = 10;  // matrix 变为 [[1, 10], [3, 4]]
```

### AST 结构设计

```zig
pub const IndexAssignment = struct {
    token: Token,           // '[' token
    left: *Expression,      // 被索引的表达式 (arr, hash, etc.)
    index: *Expression,     // 索引表达式
    value: *Expression,     // 赋值的值
};
```

### 解析策略

索引赋值需要在解析器中特殊处理：
1. 当遇到 `identifier[index]` 后跟 `=` 时，解析为索引赋值
2. 否则解析为普通索引表达式
