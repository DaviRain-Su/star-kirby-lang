# Story: v0.3.0 高级语言特性

> 实现Monkey语言的高级特性，包括运算符优先级、函数、条件表达式等

## 目标

完善Monkey语言实现，支持完整的编程语言特性，包括：
- 运算符优先级和中缀表达式解析
- 函数定义和调用
- 条件表达式(if/else)
- 字符串字面量和操作
- 数组和哈希字面量
- 索引操作
