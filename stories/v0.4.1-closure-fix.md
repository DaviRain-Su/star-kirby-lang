# Story: v0.4.1 闭包环境生命周期修复

> 修复返回闭包时 extended_env 被过早释放的问题

## 问题描述

当前实现中，返回闭包（返回捕获外部变量的函数）存在内存安全问题：

```monkey
let makeAdder = fn(x) {
    fn(y) { x + y }  // 返回一个捕获了 x 的闭包
};
let add5 = makeAdder(5);  // add5 应该能访问 x=5
add5(10)  // 应该返回 15，但目前会失败
```

### 根本原因

在 `evaluator.zig` 的 `evalCallExpression` 函数中：

```zig
// 第 410-413 行
var extended_env = try Environment.initEnclosed(allocator, fn_env);
defer extended_env.deinit();  // <-- 问题：返回后立即释放

// ... 评估函数体 ...
return evaluated;  // 如果 evaluated 是闭包，它仍持有 extended_env 的引用
```

当函数返回一个闭包时，闭包的 `env` 字段指向 `extended_env`。但 `defer` 会在函数返回后立即释放 `extended_env`，导致闭包持有悬空指针。

## 目标

1. 修复闭包环境生命周期问题
2. 确保返回的闭包能正确访问捕获的变量
3. 保持内存安全，无泄漏
4. 所有现有测试继续通过

## 技术方案

### 方案 A: 条件释放（推荐）

只在返回值不是函数对象时才释放 `extended_env`：

```zig
var extended_env = try Environment.initEnclosed(allocator, fn_env);
errdefer extended_env.deinit();  // 只在错误时释放

// ... 评估函数体 ...

// 只有返回值不是函数时才释放环境
if (evaluated.objectType() != .function) {
    extended_env.deinit();
}

return evaluated;
```

**优点**: 最小改动
**缺点**: 可能导致内存泄漏（闭包的环境永远不会被释放）

### 方案 B: 环境引用计数

为 Environment 添加引用计数：

```zig
pub const Environment = struct {
    allocator: std.mem.Allocator,
    store: std.StringHashMap(Object),
    outer: ?*Environment,
    ref_count: u32,  // 新增

    pub fn retain(self: *Environment) void {
        self.ref_count += 1;
    }

    pub fn release(self: *Environment) void {
        self.ref_count -= 1;
        if (self.ref_count == 0) {
            self.deinit();
        }
    }
};
```

**优点**: 自动内存管理
**缺点**: 增加复杂性，需要在所有使用 env 的地方调用 retain/release

### 方案 C: Arena Allocator 扩展生命周期

将环境分配到更长生命周期的 allocator：

```zig
// 在 REPL 或顶层持有一个 arena
var env_arena = std.heap.ArenaAllocator.init(allocator);
// 所有 extended_env 都从这里分配
```

**优点**: 简单实现
**缺点**: 延迟释放，可能增加内存占用

## 测试用例

```monkey
// 基本闭包
let makeAdder = fn(x) { fn(y) { x + y } };
let add5 = makeAdder(5);
add5(10)  // 应返回 15

// 多个闭包
let add10 = makeAdder(10);
add5(3) + add10(3)  // 应返回 8 + 13 = 21

// 嵌套闭包
let makeMultiplier = fn(x) {
    fn(y) {
        fn(z) { x * y * z }
    }
};
let m2 = makeMultiplier(2);
let m2_3 = m2(3);
m2_3(4)  // 应返回 2 * 3 * 4 = 24

// 闭包保持状态
let makeCounter = fn() {
    let count = 0;
    fn() {
        count = count + 1;  // 需要变量赋值支持
        count
    }
};
```
