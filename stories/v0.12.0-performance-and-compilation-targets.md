# Story: v0.12.0 性能优化和编译目标

> 实现字节码缓存、WebAssembly 支持和执行性能优化

## 目标

提升 Monkey 语言解释器的执行性能，并添加新的编译目标支持。

## 验收标准

### 1. 字节码缓存系统 (cache.zig, main.zig)

- [x] 实现缓存元数据系统（哈希和时间戳）
- [x] 磁盘缓存系统实现
- [x] 缓存一致性检查（基于文件修改时间和内容哈希）
- [x] 缓存管理功能（清理、统计）
- [x] 缓存系统单元测试

#### 技术实现
- SHA256 哈希计算用于内容校验
- 文件修改时间戳验证
- 缓存文件存储在 .star-cache 目录
- 基于文件路径的哈希生成缓存文件名

### 2. WebAssembly 编译目标 (wasm.zig, build.zig)

- [x] WebAssembly 模块生成器
- [x] 基本算术操作的 WASM 代码生成
- [x] WASM 内存模型适配
- [x] WASM 模块导出和导入
- [x] WASM 模块验证功能
- [x] WASM 模块生成测试
- [x] WASM 算术运算测试

#### 技术实现
- 自定义 WASM 二进制格式生成器
- AST 到 WASM 指令的转换
- 使用 std.wasm 标准库
- 支持基本运算符 (+, -, *, /, %)

### 3. 执行引擎优化 (evaluator.zig, object.zig, object_pool.zig)

- [x] 对象池实现（减少频繁分配）
- [x] 内联缓存系统（属性访问加速）
- [x] 函数调用缓存（纯函数结果缓存）
- [x] 缓存统计和性能监控
- [x] 对象池单元测试

#### 技术实现
- 对象池模式复用常用对象（整数、布尔值、字符串）
- 属性访问缓存机制（InlineCache 结构）
- 函数调用结果缓存（FunctionCallCache 结构）
- 池大小限制和自动清理

### 4. 构建系统增强 (build.zig)

- [x] WASM 构建目标支持 (`zig build wasm`)
- [x] 性能分析构建模式 (`zig build profile`)
- [x] 性能分析运行模式 (`zig build profile-run`)

#### 技术实现
- 使用 `b.addLibrary` API (Zig 0.15+)
- WASM 目标: wasm32-freestanding
- Profile 模式使用 ReleaseFast 优化
