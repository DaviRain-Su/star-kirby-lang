## 技术设计

### 运算符优先级

```
优先级从低到高:
1. || (逻辑或)
2. && (逻辑与)  
3. == != (相等性)
4. < > <= >= (比较)
5. + - (加减)
6. * / % (乘除模)
7. - ! (前缀)
8. () [] (调用/索引)
```

### Token 新增

```zig
pub const TokenType = enum {
    // ... existing ...
    LTE,      // <=
    GTE,      // >=
    PERCENT,  // %
    AND,      // &&
    OR,       // ||
    WHILE,    // while
};
```

### AST 新增

```zig
pub const WhileStatement = struct {
    token: token_mod.Token,
    condition: *Expression,
    body: *BlockStatement,
};

pub const Statement = union(enum) {
    // ... existing ...
    while_stmt: WhileStatement,
};
```

## 测试用例

```monkey
// 比较运算符
5 <= 5      // true
5 >= 5      // true
10 % 3      // 1

// 逻辑运算符
true && false   // false
true || false   // true
1 < 2 && 2 < 3  // true

// 新内置函数
str(42)         // "42"
int("42")       // 42
keys({"a": 1})  // [array of keys]
values({"a": 1}) // [array of values]

// while 循环
let sum = 0;
let i = 0;
while (i < 5) {
    let sum = sum + i;
    let i = i + 1;
};
sum  // 10 (0+1+2+3+4)
```
